# ADR 003: Internationalization — Auto-detect (PT-PT / PT-BR / EN Fallback)

## Status
Accepted (2026-09-09, revised 2026-09-12). Implemented in `v0.3.2-alpha` (`05305b3`).

## Context
Application UI is in English. User base includes Portuguese speakers (Portugal / Brazil). Post-alpha plan (`PLANO.md`) deferred i18n; `v0.3.2-alpha` completed it.

## Decision
- Auto-detect `navigator.language` at runtime.
- Fallback chain: `pt-PT` → `pt-BR` → `en`.
- Translation file: `src/i18n/index.ts`.
- Translated components: `HomeScreen`, `CreateDrawerModal`, `PasswordModal`, `DeleteConfirmModal`, `ViewDrawer`.
- CI fix (`detectLocale`): `process.env.CI` forces `en` in CI (`tests/ViewDrawer.test.tsx` adjusted).

## Consequences
- `PROMPT.md` removed (`v0.3.2-alpha`).
- `CHANGELOG.md` and `SECURITY.md` remain in English (documentation language policy per `PLANO.md`).
- All documentation (`CHANGELOG.md`, `SECURITY.md`, `CONTRIBUTING.md`, `docs/adr/`) in English; project communications may use PT-PT.
